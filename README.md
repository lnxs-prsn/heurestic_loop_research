# Heuristic Harness

An external, growing heuristic library for AI coding agents (Cline + DeepSeek
first; agent-agnostic by design). Heuristics are cue-indexed markdown files
served by a local MCP server, grown from logged experience through a
human-gated staging airlock, with autonomy earned in phases.
